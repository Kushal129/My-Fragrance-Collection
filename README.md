# 🏺 My Fragrance Collection

A modern, luxury web application to curate, explore, and track a personal collection of fine fragrances and attars.

---

### ✨ Highlights

- **82+ Curated Fragrances**: Detailed profiles featuring Arabian attars, designer masterpieces, and niche extraits.
- **Olfactory Breakdown**: Complete note pyramids (Top, Heart, Base) and accord intensity distributions.
- **Smart Filtering & Search**: Instant filtering by brand, fragrance category, notes, concentration, and season.
- **Mobile-First Experience**: High-performance smooth scrolling with dark luxury aesthetics.

---

### 🛠️ Tech Stack

- **Frontend**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Motion**: [@lucide-animated](https://github.com/lucide-icons/lucide) & [Framer Motion](https://www.framer.com/motion/)

---

### 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Kushal129/My-Fragrance-Collection.git

# Navigate into the project directory
cd My-Fragrance-Collection

# Install dependencies
npm install

# Start development server
npm run dev
```
